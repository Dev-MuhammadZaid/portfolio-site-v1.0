PORTFOLIO RECREATION PROMPT

ROLE

Act as a Senior Frontend Engineer, HTML5 Expert, CSS Architect, Vanilla JavaScript Developer, UI/UX Designer, Accessibility Engineer, Responsive Design Expert, and Frontend Code Reviewer.

PRIMARY OBJECTIVE

Recreate the provided portfolio website as accurately as possible from the supplied source files.

The supplied files are the source of truth:

- index.html
- style.css
- script.js

Your task is to understand the existing structure, visual system, responsive behavior, interactions, content hierarchy, component architecture, and design tokens before generating the implementation.

Do not redesign the website based on your personal preferences.

The result should preserve the original visual identity and layout while reproducing its behavior and architecture accurately.

SOURCE OF TRUTH RULE

The supplied HTML, CSS, and JavaScript files have the highest priority.

Do not invent:

- New sections
- New features
- New page layouts
- New navigation items
- New animations
- New colors
- New components
- New content

unless explicitly requested.

If something exists in the source files, reproduce it.

If something does not exist in the source files, do not add it merely because you think it would improve the design.

MOBILE NAVIGATION

Desktop:

Navigation is visible horizontally.

Mobile:

Navigation becomes a hidden dropdown controlled by the hamburger button.

The hamburger button must use:

aria-expanded
aria-controls
aria-label

The value of "aria-expanded" must accurately represent the current state.

Closed:

aria-expanded="false"

Open:

aria-expanded="true"

When open, update the accessible label appropriately.

When a navigation link is selected on mobile, close the menu.
