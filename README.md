## Theme System

The website uses CSS custom properties to control its visual system.

The JavaScript layer is responsible for:

1. Reading the saved theme.
2. Applying the theme.
3. Switching between light and dark mode.
4. Saving the selected theme.
5. Updating the theme control.

The CSS layer controls the actual colors and visual appearance of each theme.

---

### JavaScript Responsibilities

The project intentionally keeps JavaScript small.

JavaScript handles:

- Theme switching
- Theme persistence
- Mobile navigation
- Navigation accessibility state
- Scroll detection
- Scroll-to-top behavior

The project does not use a JavaScript framework.

### Development Philosophy

The project follows a simple frontend architecture:

HTML
Content + Structure

CSS
Design + Layout + Responsive Behavior

JavaScript
Interaction + Browser Behavior

The project also uses reusable CSS components such as:

.btn
.btn-primary
.btn-secondary
.section-card

This avoids unnecessary duplication while keeping the code understandable.
